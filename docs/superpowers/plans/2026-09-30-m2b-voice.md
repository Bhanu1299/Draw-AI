# M2b: Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Click **● Start**, talk while you draw, click **■ Stop**. Each thing you said is tied to the mark you drew while saying it, the panel shows that, and the edit (or a build, for a loose sketch) is sent automatically. The `I` key switches between drawing and clicking inside the live page.

**Architecture:**
- **The browser records the mic itself.** An AudioWorklet delivers raw samples, a streaming downsampler turns them into 16 kHz PCM16, and the audio goes out in 100 ms chunks. Audio is buffered from the moment of the click, so words said before the socket opens aren't lost. The time of the first sample anchors every word on the same `Date.now()` clock the strokes use.
- **ElevenLabs Scribe v2 Realtime** transcribes over a websocket that the browser opens with a single-use token from `POST /api/stt-token`, so the key never leaves the server. The commit is manual, on Stop, and the committed transcript comes back with word-level timestamps.
- **Binding is a pure function.** A word said within ±0.4 s of a mark's drawing time belongs to that mark. The remaining words form speech-only runs, which break wherever a mark was drawn between them. The result is an ordered list of `SpeechRun { mark: n | null, text }`.
- **The server gets the speech runs next to the marks.** The prompt lists them in time order with `[n]` tags. Everything else in the M2a edit pipeline is unchanged.
- **Stop decides what to do,** in a pure function. If there are marks on a page, it edits. If a sketch is selected, or loose strokes lie far from any page, it builds. With nothing drawn, it edits the whole page. If nothing was said, it answers "Didn't catch that".
- **Interact mode** is a tldraw atom. In it, the frames and iframes take pointer events. The preview forwards the `I` and `Escape` keys to the board (focus sits in the iframe after a click), blocks navigation away from the page, and re-reports element rects after DOM changes.

**Tech Stack:** Node 22 · Next.js 16.3.6 (App Router) · React 19.3.0 · tldraw 5.4.2 · **@elevenlabs/client 1.26.0 (new, pinned)** · Vitest 5.0.2 · TypeScript 5.9.3

**Spec:** `docs/superpowers/specs/2026-09-28-drawai-v1-design.md`. This plan implements the second half of milestone M2 (§11), so read §2.2, §4 and §8 before starting. The M2a plan (`docs/superpowers/plans/2026-09-29-m2a-point-and-edit.md`) explains the mark pipeline this plan builds on.

## Decisions made for this plan (spec deviations; Task 11 records them in the spec)

1. **The speech-to-text provider is ElevenLabs Scribe v2 Realtime** (`scribe_v2_realtime`), chosen by the owner on 2026-09-30. The spec's default was Deepgram, with the pick left for planning. It streams, gives word timestamps and issues single-use browser tokens. We use a manual commit, `includeTimestamps`, `noVerbatim` (drops "um"/"uh") and a short list of UI keyterms.
2. **We capture the mic ourselves instead of using the SDK's microphone mode.** The SDK only starts the mic after the socket opens and doesn't say when audio started, but binding needs the exact start time. Our own capture also lets us buffer from the click.
3. **Only marks get numbers.** Spec §4.2 step 4 numbers speech-only segments too. We show them instead as unnumbered quoted rows in time order, which keeps the badges 1…N stable and still matches typed references like "1 smaller". The prompt still sends everything in time order.
4. **The mic button lives in the instruction panel,** not a bottom toolbar, because tldraw's own toolbar occupies the bottom.
5. **Voice can build** (spec §2.3, "From M2… ■ Stop builds it"). If no marks sit on a page and either a sketch or screenshot is selected or loose strokes lie far from every page, Stop builds with the transcript as the note.
6. **With exactly one page on the board and nothing drawn,** an instruction applies to that page without selecting it first. This applies to both typed and spoken instructions.
7. **Words bind after Stop,** when Scribe returns word timings for the commit. While recording, the panel shows the live partial transcript. Live binding stays deferred (§12 item 4).
8. **Tool shapes' time spans cover the whole drag.** In M2a an ellipse or arrow had `t1 = t0`. Now `t1` follows the pointer until it is released, so words said while dragging bind to that shape.
9. **The Playwright end-to-end tests (§9.3) move to M3,** alongside the auth shell. M2b covers the logic with unit tests plus a live checklist (Task 11).

## Global Constraints

- Node `>=22.12` (`.nvmrc` = `22`). Run `nvm use` before any `npm` command.
- This Next.js has breaking changes. New route handlers copy the pattern in `src/app/api/edit/route.ts`. Read `node_modules/next/dist/docs/` before using any Next API not already in the repo.
- **STT:** `scribe_v2_realtime` · PCM16 mono **16 kHz**, little-endian · **100 ms** chunks (1600 samples) · `commitStrategy: manual` · `includeTimestamps: true` · `noVerbatim: true`.
- The key lives only on the server, as `ELEVENLABS_API_KEY` in `.env.local`. The browser only ever gets single-use tokens from `POST /api/stt-token`.
- **Binding window:** ±**400 ms** around a mark's `[t0, t1]` (spec §4.2). Grouping stays at 1.2 s / 80 px.
- **Recording cap:** **60 s**, after which it stops automatically. **Stop waits at most 5 s** for the session to open and at most 5 s more for the final words, and never hangs.
- **Speech caps on `/api/edit`:** at most **60** runs, **4000** characters in total, and every run's text must be non-empty. `mark` is `null` or an integer ≥ 1.
- The `@elevenlabs/client` SDK is loaded with a dynamic `import()` only when the user presses ● Start, so it adds nothing to the board's initial load.
- **Local only until M3.** `/api/stt-token` is unauthenticated, so anyone who can reach the dev server can spend the owner's voice credits.
- Every failure the user sees says what to do next. Typing in the panel always works as the fallback (spec §8).
- Modules that tests import must not import `tldraw` at runtime (type-only imports are fine). Pure logic goes in its own file.

```ts
import type { Word } from '@/marks/types';

/** A word as the STT returns it: seconds from the start of the audio. Spacing and audio events are skipped. */
export interface SttWord {
  text: string;
  start?: number;
  end?: number;
  type: string;
}

/** Move STT words onto the stroke clock. `audioStartMs` is when the first audio sample was captured. */
export function toWords(raw: SttWord[], audioStartMs: number): Word[] {
  return raw.flatMap((w) => {
    const text = w.text.trim();
    if (w.type !== 'word' || !text || typeof w.start !== 'number' || typeof w.end !== 'number') return [];
    return [{ text, t0: audioStartMs + w.start * 1000, t1: audioStartMs + Math.max(w.start, w.end) * 1000 }];
  });
}

export const transcriptOf = (words: Word[]): string => words.map((w) => w.text).join(' ');
```

`src/marks/bindWords.ts`:
```ts
import type { SpeechRun } from '@/shared/types';
import type { Word } from './types';

/** A word said this close to a mark's drawing time belongs to that mark (spec §4.2). */
export const BIND_PAD_MS = 400;

export interface TimedMark {
  n: number;
  t0: number;
  t1: number;
}

export interface BoundRun extends SpeechRun {
  t0: number;
  t1: number;
}

/**
 * Split what was said into runs, in time order. Words said while a mark was drawn (± 0.4 s) go to that
 * mark; the rest form speech-only runs, which break wherever a mark was drawn between two words.
 */
export function bindWords(marks: TimedMark[], words: Word[]): BoundRun[] {
  const runs: BoundRun[] = [];
  for (const word of [...words].sort((a, b) => a.t0 - b.t0)) {
    const mark = ownerOf(word, marks);
    const last = runs.at(-1);
    const markBetween = !!last && marks.some((m) => m.t0 >= last.t1 && m.t0 <= word.t0);
    if (last && last.mark === mark && (mark !== null || !markBetween)) {
      last.text += ` ${word.text}`;
      last.t1 = Math.max(last.t1, word.t1);
    } else {
      runs.push({ mark, text: word.text, t0: word.t0, t1: word.t1 });
    }
  }
  return runs;
}

/** The closest mark whose padded window the word overlaps; on a tie, the earlier mark. */
function ownerOf(word: Word, marks: TimedMark[]): number | null {
  let best: TimedMark | null = null;
  let bestGap = Infinity;
  for (const m of marks) {
    if (word.t1 < m.t0 - BIND_PAD_MS || word.t0 > m.t1 + BIND_PAD_MS) continue;
    const gap = Math.max(0, m.t0 - word.t1, word.t0 - m.t1);
    if (gap < bestGap) {
      best = m;
      bestGap = gap;
    }
  }
  return best ? best.n : null;
}

export const toSpeech = (runs: BoundRun[]): SpeechRun[] => runs.map(({ mark, text }) => ({ mark, text }));

export type TimelineRow<M> = { kind: 'mark'; mark: M; said: string } | { kind: 'speech'; text: string };

/** Marks (with what was said while drawing them) and speech-only runs, in the order they happened. */
export function timeline<M extends TimedMark>(marks: M[], runs: BoundRun[]): TimelineRow<M>[] {
  const rows: Array<{ t: number; row: TimelineRow<M> }> = [
    ...marks.map((mark) => ({
      t: mark.t0,
      row: {
        kind: 'mark' as const,
        mark,
        said: runs
          .filter((r) => r.mark === mark.n)
          .map((r) => r.text)
          .join(' … '),
      },
    })),
    ...runs.filter((r) => r.mark === null).map((r) => ({ t: r.t0, row: { kind: 'speech' as const, text: r.text } })),
  ];
  return rows.sort((a, b) => a.t - b.t).map((r) => r.row);
}
```

```ts
import type { SttTokenResponse } from '@/shared/types';

export const SCRIBE_TOKEN_URL = 'https://api.elevenlabs.io/v1/single-use-token/realtime_scribe';
const TIMEOUT_MS = 10_000;

export const VOICE_NOT_SET_UP =
  "Voice isn't set up: add ELEVENLABS_API_KEY to .env.local and restart the server. You can type your instruction meanwhile.";

/** Mint a single-use Scribe token, so the browser can stream audio without ever seeing our key. */
export async function mintSttToken(env: Record<string, string | undefined>, fetchFn: typeof fetch = fetch): Promise<SttTokenResponse> {
  const key = env.ELEVENLABS_API_KEY?.trim();
  if (!key) return { ok: false, error: VOICE_NOT_SET_UP };
  let res: Response;
  try {
    res = await fetchFn(SCRIBE_TOKEN_URL, { method: 'POST', headers: { 'xi-api-key': key }, signal: AbortSignal.timeout(TIMEOUT_MS) });
  } catch {
    return { ok: false, error: "Couldn't reach the voice service. Check your connection, or type your instruction." };
  }
  if (res.status === 401 || res.status === 403) {
    return { ok: false, error: 'The voice service rejected ELEVENLABS_API_KEY. Check the key and its speech-to-text permission.' };
  }
  if (!res.ok) return { ok: false, error: `The voice service failed (HTTP ${res.status}). Try again, or type your instruction.` };
  const body = (await res.json().catch(() => null)) as { token?: unknown } | null;
  if (typeof body?.token !== 'string' || body.token === '') {
    return { ok: false, error: 'The voice service sent an unexpected reply. Try again, or type your instruction.' };
  }
  return { ok: true, token: body.token };
}
```

`src/voice/pcm.ts`:
```ts
export const STT_SAMPLE_RATE = 16_000;

/**
 * A streaming average-downsampler to 16 kHz (mics usually run at 44.1 or 48 kHz). It keeps the fractional
 * read position between chunks: dropping it would shorten the audio ~1% and push word timings off the strokes.
 */
export function createDownsampler(inRate: number, outRate = STT_SAMPLE_RATE): (chunk: Float32Array) => Float32Array {
  if (inRate < outRate) throw new Error(`Cannot upsample ${inRate} Hz audio to ${outRate} Hz.`);
  if (inRate === outRate) return (chunk) => chunk;
  const ratio = inRate / outRate;
  let pending = new Float32Array(0);
  let pos = 0; // where the next output sample starts, in `pending` (fractional)
  return (chunk) => {
    const buf = new Float32Array(pending.length + chunk.length);
    buf.set(pending);
    buf.set(chunk, pending.length);
    const out: number[] = [];
    while (pos + ratio <= buf.length) {
      const from = Math.floor(pos);
      const to = Math.floor(pos + ratio);
      let sum = 0;
      for (let j = from; j < to; j++) sum += buf[j];
      out.push(sum / Math.max(1, to - from));
      pos += ratio;
    }
    const used = Math.floor(pos);
    pending = buf.slice(used);
    pos -= used;
    return Float32Array.from(out);
  };
}

/** Float samples → base64 of little-endian signed 16-bit PCM, the format Scribe expects. */
export function toPcm16Base64(samples: Float32Array): string {
  const bytes = new Uint8Array(samples.length * 2);
  const view = new DataView(bytes.buffer);
  samples.forEach((s, i) => {
    const c = Math.max(-1, Math.min(1, s));
    view.setInt16(i * 2, c < 0 ? c * 0x8000 : c * 0x7fff, true);
  });
  let binary = '';
  for (let i = 0; i < bytes.length; i += 0x8000) binary += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  return btoa(binary);
}
```

```ts
export type SttError = { kind: 'no-speech' } | { kind: 'failed'; message: string };

const failed = (message: string): SttError => ({ kind: 'failed', message });

/** Turn a Scribe error message (or a local error) into what the user should see. */
export function sttError(data: unknown): SttError {
  const record = (typeof data === 'object' && data !== null ? data : {}) as { message_type?: unknown; error?: unknown };
  const detail = typeof record.error === 'string' ? record.error : data instanceof Error ? data.message : '';
  switch (record.message_type) {
    case 'insufficient_audio_activity':
      return { kind: 'no-speech' };
    case 'auth_error':
      return failed('The voice service rejected the session. Check ELEVENLABS_API_KEY, or type your instruction.');
    case 'quota_exceeded':
      return failed('Voice credits ran out (ElevenLabs quota). Type your instruction instead.');
    case 'rate_limited':
    case 'resource_exhausted':
    case 'queue_overflow':
      return failed('The voice service is busy. Wait a moment and press ● Start again.');
    case 'session_time_limit_exceeded':
      return failed('That recording ran too long. Keep one instruction under a minute.');
    default:
      return failed(`Voice stopped working${detail ? ` (${detail})` : ''}. Press ● Start to try again, or type below.`);
  }
```

```ts
class DrawaiCapture extends AudioWorkletProcessor {

  stop(): void;

/** Stream mono mic samples to onSamples. Rejects with the browser's DOMException (e.g. NotAllowedError) on failure. */
export async function startMicCapture(onSamples: (samples: Float32Array, sampleRate: number) => void): Promise<MicStream> {
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true, channelCount: 1, sampleRate: { ideal: 16_000 } },
  });
  // Firefox requires the context to run at the mic's own rate.
  const rate = stream.getAudioTracks()[0]?.getSettings().sampleRate;
  const context = new AudioContext(rate ? { sampleRate: rate } : undefined);
  const release = () => {
    stream.getTracks().forEach((t) => t.stop());
    void context.close();
  };
  try {
    const url = URL.createObjectURL(new Blob([PROCESSOR], { type: 'application/javascript' }));
    try {
      await context.audioWorklet.addModule(url);
    } finally {
      URL.revokeObjectURL(url);
    }
    const source = context.createMediaStreamSource(stream);
    const node = new AudioWorkletNode(context, 'drawai-capture');
    node.port.onmessage = (e: MessageEvent<Float32Array>) => onSamples(e.data, context.sampleRate);
    source.connect(node);
    if (context.state === 'suspended') await context.resume();
    return {
      stop() {
        node.port.onmessage = null;
        source.disconnect();
        node.disconnect();
        release();
      },
    };
  } catch (err) {
    release();
    throw err;
  }
}
```

```ts
import type { Word } from '@/marks/types';
import type { MicStream } from './micCapture';
import { createDownsampler, STT_SAMPLE_RATE, toPcm16Base64 } from './pcm';
import type { SttError } from './sttErrors';
import { toWords, type SttWord } from './words';

export const MAX_RECORDING_MS = 60_000;
export const FINAL_WORDS_TIMEOUT_MS = 5_000;
/** Audio goes out in 100 ms chunks. */
const CHUNK_SAMPLES = STT_SAMPLE_RATE / 10;

export const MIC_DENIED =
  'Microphone access is blocked. Allow it for this site (the icon left of the address bar), or type your instruction below.';
export const NO_MIC = 'No microphone found. Connect one, or type your instruction below.';
export const DIDNT_CATCH = "Didn't catch that. Press ● Start and try again, or type below.";
export const NO_RESPONSE = "The voice service didn't respond. Press ● Start to try again, or type below.";
const LOST = 'Lost the connection to the voice service. Press ● Start to try again.';
const NO_TOKEN = "Couldn't reach the server for voice. Check that it is running, or type your instruction.";

export class VoiceError extends Error {
  override name = 'VoiceError';
}

/** The STT session as the recorder sees it: the ElevenLabs adapter (scribeSocket.ts), or a fake in tests. */
export interface SttEvents {
  onOpen(): void;
  onPartial(text: string): void;
  onWords(words: SttWord[]): void;
  onError(error: SttError): void;
  onClose(): void;
}

export interface SttSocket {
  send(pcm16Base64: string): void;
  commit(): void;
  close(): void;
}

export interface RecorderDeps {
  fetchToken(): Promise<{ ok: true; token: string } | { ok: false; error: string }>;
  connect(token: string, events: SttEvents): SttSocket;
  startMic(onSamples: (samples: Float32Array, sampleRate: number) => void): Promise<MicStream>;
  /** The stroke clock (Date.now). */
  now(): number;
  finalWordsTimeoutMs?: number;
}

export interface RecorderCallbacks {
  onPartial(text: string): void;
  /** The session broke while recording. The recording is already cancelled. */
  onFailure(message: string): void;
}

export interface Recording {
  /** Stop listening and return every word said, on the stroke clock. Never hangs. */
  stop(): Promise<Word[]>;
  cancel(): void;
}

/** Start the mic right away (buffering), mint a token and open the STT session in parallel. */
export async function startRecording(deps: RecorderDeps, callbacks: RecorderCallbacks): Promise<Recording> {
  const token = deps.fetchToken().catch(() => ({ ok: false as const, error: NO_TOKEN }));
  const outbox: string[] = [];
  const pcm: number[] = [];
  const raw: SttWord[] = [];
  const waiters = new Set<() => void>();
  let downsample: ((chunk: Float32Array) => Float32Array) | null = null;
  let audioStart: number | null = null;
  let socket: SttSocket | null = null;
  let open = false;
  let closed = false;
  let stopping = false;
  let done = false;
  let noSpeech = false;
  let failure: string | null = null;
  let wordEvents = 0;

  const notify = () => waiters.forEach((w) => w());
  function until(cond: () => boolean, ms: number): Promise<void> {
    if (cond()) return Promise.resolve();
    return new Promise((resolve) => {
      const finish = () => {
        clearTimeout(timer);
        waiters.delete(check);
        resolve();
      };
      const check = () => {
        if (cond()) finish();
      };
      const timer = setTimeout(finish, ms);
      waiters.add(check);
    });
  }
  function flush() {
    if (!socket || !open || closed) return;
    for (const chunk of outbox.splice(0)) socket.send(chunk);
  }
  function pack(all: boolean) {
    while (pcm.length >= CHUNK_SAMPLES || (all && pcm.length > 0)) {
      outbox.push(toPcm16Base64(Float32Array.from(pcm.splice(0, CHUNK_SAMPLES))));
    }
    flush();
  }

  let mic: MicStream;
  try {
    mic = await deps.startMic((samples, rate) => {
      if (stopping || done) return;
      audioStart ??= deps.now() - (samples.length / rate) * 1000;
      downsample ??= createDownsampler(rate);
      for (const s of downsample(samples)) pcm.push(s);
      pack(false);
    });
  } catch (err) {
    throw new VoiceError(micMessage(err));
  }
  const minted = await token;
  if (!minted.ok) {
    mic.stop();
    throw new VoiceError(minted.error);
  }

  function cancel() {
    if (done) return;
    done = true;
    mic.stop();
    socket?.close();
  }
  function fail(message: string) {
    if (done) return;
    if (stopping) {
      failure ??= message; // stop() is waiting: let it report this
      notify();
      return;
    }
    failure = message;
    cancel();
    callbacks.onFailure(message);
  }

  socket = deps.connect(minted.token, {
    onOpen: () => {
      open = true;
      flush();
      notify();
    },
    onPartial: (text) => callbacks.onPartial(text),
    onWords: (words) => {
      raw.push(...words);
      wordEvents++;
      notify();
    },
    onError: (e) => {
      if (e.kind === 'no-speech') {
        noSpeech = true;
        notify();
      } else fail(e.message);
    },
    onClose: () => {
      closed = true;
      notify();
      if (!stopping) fail(LOST);
    },
  });

  async function stop(): Promise<Word[]> {
    if (done) throw new VoiceError(failure ?? DIDNT_CATCH);
    stopping = true;
    mic.stop();
    pack(true);
    const wait = deps.finalWordsTimeoutMs ?? FINAL_WORDS_TIMEOUT_MS;
    try {
      await until(() => open || closed || failure !== null, wait);
      if (failure) throw new VoiceError(failure);
      if (!open) throw new VoiceError(NO_RESPONSE);
      const start = audioStart;
      if (start === null) return [];
      if (!closed) {
        flush();
        const before = wordEvents;
        socket?.commit();
        await until(() => wordEvents > before || noSpeech || closed || failure !== null, wait);
        if (failure) throw new VoiceError(failure);
      }
      return toWords(raw, start);
    } finally {
      done = true;
      socket?.close();
    }
  }

  return { stop, cancel };
}

function micMessage(err: unknown): string {
  const name = (err as { name?: unknown } | null)?.name;
  if (name === 'NotAllowedError' || name === 'SecurityError') return MIC_DENIED;
  if (name === 'NotFoundError' || name === 'OverconstrainedError') return NO_MIC;
  return "Couldn't start the microphone. Try again, or type your instruction below.";
}
```

```ts
  'navbar', 'nav', 'hero', 'CTA', 'header', 'footer', 'sidebar', 'card', 'cards', 'button', 'padding', 'margin',

    token,
    modelId: SCRIBE_MODEL,
    audioFormat: AudioFormat.PCM_16000,
    sampleRate: STT_SAMPLE_RATE,
    commitStrategy: CommitStrategy.MANUAL,
    includeTimestamps: true,
    noVerbatim: true,
    keyterms: UI_KEYTERMS,
  });

  connection.on(RealtimeEvents.PARTIAL_TRANSCRIPT, (m) => events.onPartial(m.text));
  connection.on(RealtimeEvents.COMMITTED_TRANSCRIPT_WITH_TIMESTAMPS, (m) => events.onWords(m.words ?? []));
  // ERROR fires for every specific error type too, so this one listener sees them all.
  connection.on(RealtimeEvents.ERROR, (m) => events.onError(sttError(m)));
  connection.on(RealtimeEvents.CLOSE, () => events.onClose());
  return {
    send: (audioBase64) => connection.send({ audioBase64 }),
    commit: () => connection.commit(),
    close: () => connection.close(),
  };
}
```

```ts
import type { EditPlan, PlanResult } from '@/marks/planEdit';
import { DIDNT_CATCH } from '@/voice/recorder';

export interface VoiceContext {
  /** The transcript. */
  said: string;
  /** Whatever is in the panel's text box. */
  typed: string;
  plan: PlanResult;
  /** The selection is a sketch or a screenshot (not a page). */
  selectionBuildable: boolean;
  /** Pending strokes far from every page. */
  looseShapeIds: string[];
}

export type VoiceAction =
  | { kind: 'edit'; plan: EditPlan }
  | { kind: 'build'; from: 'selection' | string[] }
  | { kind: 'none'; message: string };

/** What ■ Stop does. Marks on a page win; a sketch builds; with nothing drawn, the whole page changes. */
export function decideVoiceAction(c: VoiceContext): VoiceAction {
  if (!c.said.trim() && !c.typed.trim()) return { kind: 'none', message: DIDNT_CATCH };
  if (c.plan.ok && c.plan.plan.marks.length > 0) return { kind: 'edit', plan: c.plan.plan };
  if (!c.plan.ok && c.plan.reason === 'loading') return { kind: 'none', message: c.plan.message };
  if (c.selectionBuildable) return { kind: 'build', from: 'selection' };
  if (c.looseShapeIds.length > 0) return { kind: 'build', from: c.looseShapeIds };
  if (c.plan.ok) return { kind: 'edit', plan: c.plan.plan };
  return { kind: 'none', message: c.plan.message };
}

export function formatElapsed(ms: number): string {
  const s = Math.max(0, Math.floor(ms / 1000));
  return `${Math.floor(s / 60)}:${String(s % 60).padStart(2, '0')}`;
}
```

```ts
    editStatus.set({ phase: 'error', text: err instanceof VoiceError ? err.message : DIDNT_CATCH });
    return;
  }
  voiceState.set(IDLE_VOICE);
  if (await actOnVoice(editor, words, instructionDraft.get())) instructionDraft.set('');
}

/** Drop the recording without acting on it. */
export function cancelVoice(): void {
  clearTimeout(autoStop);
  recording?.cancel();
  recording = null;
  voiceState.set(IDLE_VOICE);
}

async function actOnVoice(editor: Editor, words: Word[], typed: string): Promise<boolean> {
  const said = transcriptOf(words);
  const action = decideVoiceAction({
    said,
    typed,
    plan: currentPlan(editor),
    selectionBuildable: checkSelection(editor.getSelectedShapes()).ok,
    looseShapeIds: looseShapeIds(readPendingStrokes(editor), readFrames(editor)),
  });
  if (action.kind === 'none') {
    editStatus.set({ phase: 'error', text: action.message });
    return false;
  }
  if (action.kind === 'build') return buildFromVoice(editor, action.from, [typed.trim(), said].filter(Boolean).join('\n'));

  const runs = bindWords(action.plan.marks, words);
  voiceState.update((s) => ({ ...s, runs })); // the panel shows what each mark heard while the edit runs
  const ok = await sendEdit(editor, action.plan, typed.trim(), toSpeech(runs));
  if (ok) voiceState.update((s) => ({ ...s, runs: [] }));
  return ok;
}

async function buildFromVoice(editor: Editor, from: 'selection' | string[], note: string): Promise<boolean> {
  if (from !== 'selection') editor.select(...(from as TLShapeId[]));
  editStatus.set({ phase: 'working', text: 'Building your page…' });
  try {
    const result = await buildFromSelection(editor, note.slice(0, MAX_NOTE_CHARS));
    editStatus.set(result.ok ? { phase: 'done', text: 'Built a page from your sketch.' } : { phase: 'error', text: result.error });
    return result.ok;
  } catch {
    editStatus.set({ phase: 'error', text: 'Something went wrong while exporting your sketch. Please try again.' });
    return false;
  }
}
```

```ts
import { atom, react, type Editor } from 'tldraw';
import { interactKeyAction } from './interactKeys';

/** Interact mode: pages take clicks (links, buttons, menus) and ink is off. Draw mode is the default. */
export const interactMode = atom<boolean>('interact mode', false);

export function setInteractMode(editor: Editor, on: boolean): void {
  if (interactMode.get() === on) return;
  interactMode.set(on);
  if (on) {
    editor.setCurrentTool('select');
  } else if (document.activeElement instanceof HTMLIFrameElement) {
    // Focus stayed in the page after a click: give the keyboard back to the board.
    document.activeElement.blur();
    editor.focus();
  }
}

/** A key the preview forwarded because it had focus. */
export function applyInteractKey(editor: Editor, key: 'i' | 'Escape'): void {
  setInteractMode(editor, key === 'i' ? !interactMode.get() : false);
}

export function registerInteractMode(editor: Editor): () => void {
  const onKey = (e: KeyboardEvent) => {
    const action = interactKeyAction(e, isTyping(editor, e.target), interactMode.get());
    if (action) setInteractMode(editor, action === 'toggle' ? !interactMode.get() : false);
  };
  window.addEventListener('keydown', onKey);
  // Picking a drawing tool means the user wants ink again.
  const stop = react('leave interact mode for ink', () => {
    const tool = editor.getCurrentToolId();
    if (interactMode.get() && tool !== 'select' && tool !== 'hand') interactMode.set(false);
  });
  return () => {
    window.removeEventListener('keydown', onKey);
    stop();
  };
}

function isTyping(editor: Editor, target: EventTarget | null): boolean {
  if (editor.getEditingShapeId() !== null) return true;
  return target instanceof HTMLElement && (target.isContentEditable || ['INPUT', 'TEXTAREA', 'SELECT'].includes(target.tagName));
}
```

```ts
const plain = (t: string) => t.toLowerCase().replace(/[^\p{L}\p{N}\s]/gu, '').replace(/\s+/g, ' ').trim();

/** Speech runs in order: each must match its mark and its words (case and punctuation ignored). */
export function scoreSpeech(c: EvalCase): Score {
  if (!c.words || !c.expectedSpeech) return { correct: 0, total: 0, failures: [] };
  const result = planEdit(c.strokes, c.frames, c.selectedFrameId);
  const got = result.ok ? toSpeech(bindWords(result.plan.marks, c.words)) : [];
  const total = Math.max(got.length, c.expectedSpeech.length);
  const failures: string[] = [];
  let correct = 0;
  for (let i = 0; i < total; i++) {
    const want = c.expectedSpeech[i];
    const have = got[i];
    if (want && have && want.mark === have.mark && plain(want.text) === plain(have.text)) correct++;
    else failures.push(`${c.name} speech #${i + 1}: expected ${want ? JSON.stringify(want) : 'nothing'}, got ${have ? JSON.stringify(have) : 'nothing'}`);
  }
  return { correct, total, failures };
}
```
